# cp1-front

Correção do 1° Checkpoint de Front end, nesse cp eu tive que criar três paginas HTML, sem a utilizando de CSS ou JavaScript.

Checkpoint 1 - Front-End Web Development 🚀

Este projeto é uma aplicação web simples composta por páginas estáticas interligadas, desenvolvida como parte da avaliação de Checkpoint (CP) da disciplina de Front-End.

O objetivo do projeto é demonstrar o domínio sobre os conceitos fundamentais do HTML, incluindo estruturação de texto, navegação por hiperlinks, inserção de imagens e criação de formulários interativos.

📌 Páginas do Projeto

O site conta com 3 páginas no total:
Início (index.html):
Página principal do campus/projeto.
Contém menu de navegação em lista para transição entre as páginas.
Apresenta seções de boas-vindas, imagem temática e rodapé com direitos autorais.

Contato (contato.html):
Página dedicada para comunicação com os usuários/alunos.
